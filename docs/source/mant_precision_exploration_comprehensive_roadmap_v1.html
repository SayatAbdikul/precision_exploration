Sub-8-Bit Precision Exploration for MANT

A dependency-aware roadmap for the full numerical-format study, generic hardware evaluation, and private MANT co-development. The sequence is intentionally evidence-driven: decisions that should be learned from experiments are left open, while only the contracts required for reproducible work are frozen up front.

≤8-bit weights & activations Architecture-independent public study first Model C controlled MAC baseline Conservative pruning Generic RTL → public Pareto → MANT Sequence, not calendar

1. How to read this roadmap

CRITICAL PATHTasks that must complete before the next scientific stage can begin.
PARALLELWorkstreams that can proceed simultaneously once their shared interface is stable.
DECISION GATEA point where measured evidence selects the next branch or search scope.
FROZENA methodological decision already made and not treated as a search variable in the controlled baseline.
Core rule: do not freeze research outcomes early. Freeze only the contracts needed to make experiments comparable and software reusable. Candidate formats, accumulator widths, scale optimizations, multiplier architectures, MANT ISA changes and heterogeneous tiles remain evidence-driven.
The roadmap separates public Stage A from private Stage B. Public Stage A asks which numerical architectures are generally Pareto-efficient. Private Stage B asks which of those candidates—and selected guard candidates—fit MANT best.

2. Frozen starting decisions

IDDecision now frozenReasonWhat remains open
F1 Experiment A canonical MAC = Model C: full/exact product enters a sufficiently wide accumulator; accumulator rounding follows its own defined format. Prevents the first format comparison from being dominated by premature product rounding. Models A/B/C are still compared later for finalists and for MANT.
F2 Use a sufficiently wide, family-appropriate accumulator in the controlled Experiment A baseline. Measures representation quality before intentionally squeezing accumulation precision. Native, 8/10/12/16-bit, INT32, FP variants, quire/Kulisch-style options are later search dimensions.
F3 Weight and activation formats are independently configurable in the software architecture. Prevents a rewrite when W≠A mixed precision is explored. Experiment A may begin with uniform W=A screening; W/A asymmetry is a later sweep.
F4 Accumulator format is independently configurable from W and A. Keeps the numerical architecture explicit: W format + A format + accumulator + MAC model. Which accumulator wins is not decided now.
F5 Static PTQ; no retraining; BN folded before calibration; fixed calibration/evaluation subsets; MSE-based calibration where scale selection is required; symmetric zero-point-0 signed INT baseline; no bias correction/reconstruction in A. Creates a reproducible controlled baseline. Format-specific PTQ improvements move to Experiment B.
F6 No optional external scaling in Experiment A. Use only scaling intrinsic/necessary to the family: conventional INT/fixed-point mapping scales; native MX/BFP shared scales; direct FP/minifloat/Posit unless the format definition itself requires otherwise. Reduces optimizer bias and avoids hiding intrinsic dynamic-range behavior. General external scale, power-of-two scale, bias/range tuning, block-size and scale-granularity sweeps belong to Experiment B.
F7 Public Stage A is architecture-independent with respect to MANT. Prevents current MANT FP-only and same-word assumptions from constraining the scientific search. MANT may later be modified—or may keep its current structure—based on evidence.
F8 Private MANT evaluation receives the public Pareto set plus a conservative guard set, not only one winner. Protects against a candidate being generically near-Pareto but unusually efficient on MANT. Exact guard-set composition is decided after the public study.

Numerical / Research
  • N0.1 Write the canonical arithmetic contract for Model C.
  • N0.2 Define accumulator-format interface and conversion/rounding points.
  • N0.3 Rewrite Experiment A scaling rules: intrinsic/necessary scaling only.
  • N0.4 Freeze deployment-graph rules: eval mode → BN folding → calibration → PTQ.
  • N0.5 Define operator semantics and strict/practical low-precision modes.
Software / Reproducibility
  • I0.1 Define canonical experiment config schema.
  • I0.2 Define datatype manifest schema.
  • I0.3 Define content-hash identity rules for runs/artifacts.
  • I0.4 Define public package exported to private MANT.
Generic Hardware
  • H0.1 Freeze comparison metrics: area, fmax, II, latency, throughput, leakage, dynamic power, energy/op.
  • H0.2 Freeze hierarchy: primitive → MAC/FPU → generic PE/tile → system.
  • H0.3 Define standard register-to-register timing harness.

  • M0.1 Freeze what stays private: ISA, tile, interconnect, mapping/compiler, golden model.
  • M0.2 Define the importer boundary; do not redesign MANT yet.
Exit criterion: one experiment configuration uniquely determines the expected numerical result, and no public code needs MANT-specific knowledge.

6. Where parallel work is most valuable

Parallel cluster A — immediately after contracts

  • Workload/checkpoint preparation
  • Datatype oracle + manifests
  • Scheduler/database
  • ICS55 flow bring-up
  • MANT regression/measurement hooks

These share interfaces but not day-to-day implementation.

Parallel cluster B — promoted numerical search

  • W/A asymmetry
  • Accumulator/MAC-model sweep
  • Experiment B scaling/PTQ
  • Signedness/block-size studies
  • Rough hardware-cost modeling

Distribute complete experiment configurations across machines/GPUs.

Parallel cluster C — hardware DSE

  • INT/significand multiplier architectures
  • FP add/mul/FMA
  • Posit/MX/log-specific blocks
  • Scale/requantization RTL
  • Memory organization studies
  • Power-trace tooling

All use the same synthesis result schema and constraints.

Do not parallelize by creating inconsistent semantics. All numerical backends and RTL generators must consume the same manifest/config definitions. Parallel work should share one source of truth rather than copying format definitions into separate codebases.

7. Expected outputs by milestone

Contracts + schemas→ Reproducible FP32 baselines→ Bit-exact format library→ Exact CPU/CUDA inference→ Experiment A dataset→ Experiment B + accumulation dataset→ Full numerical finalists→ Generic RTL/PPA database→ Public Pareto frontier→ MANT Pareto + guard evaluation→ Tile/whole-chip Pareto→ MANT v1 numerical architecture

Final public research package

  • Datatype manifests and conformance tests.
  • Controlled Experiment A results under minimal/canonical family semantics.
  • Optimized Experiment B results with optional scaling/PTQ explicitly separated.
  • Accumulator and MAC-model sensitivity.
  • ImageNet + detector quality data with statistical uncertainty.
  • Generic arithmetic/scaling/memory RTL/PPA and public Pareto frontiers.
  • Clear separation of ideal bit savings from physically realizable memory savings.

Final private MANT package

  • Public-candidate importer and MANT numerical delta analysis.
  • Updated golden model and selected ISA/tile changes only where justified.
  • Full tile and whole-chip comparisons under equal area/transistor budgets.
  • Final format/storage/accumulator/scaling/requantization architecture.
  • Updated MANT architecture manual consistent with the implementation.
Most important sequencing principle: the numerical engine should be general enough to express candidate architectures before MANT is changed; generic hardware evidence should exist before selecting what MANT must support; and detailed P&R should happen only after both numerical and tile-level evidence have narrowed the field.
